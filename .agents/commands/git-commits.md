Create a focused conventional commit.

Format: `<type>(<scope>): <imperative subject>`.

Types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`.

Check `git status --short`, stage only intentional files, exclude secrets/caches/build output, and mention verification in the body when useful.

Example: `git commit -m "docs(agents): add invoice-processing agent kit"`.
