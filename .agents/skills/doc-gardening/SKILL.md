# Doc Gardening

Compare `README.md`, `AGENTS.md`, `backstage/`, environment examples, and developer commands against implemented routes, schemas, graph topology, worker behavior, and frontend surfaces.

Report stale claims, broken links, missing behavior updates, and planned behavior presented as complete. Apply safe factual fixes when authorized; separate items needing product or architecture decisions. Never include secrets, real invoices, vendor/payment details, prompts, or raw provider payloads.

Use `references/doc-coverage-checklist.md` as a supplemental checklist.
